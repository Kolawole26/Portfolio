About

Frontend engineer, team lead, mentor.

I'm a result-driven Frontend Engineer working across JavaScript, TypeScript, React, Vue, Next.js, Nuxt.js and Angular. I craft responsive interfaces with HTML5, CSS3, Sass, Tailwind CSS and Bootstrap, plus UI libraries like Quasar and Ionic, and I manage application state and data with Redux, Vuex, Pinia, Strapi, REST APIs and WebSockets.

Since 2023 I've led frontend development at Special Man Global Solution: planning and delegating work, reviewing code, and mentoring interns into productive developers. I've shipped 10+ live web applications across fintech, education, social media and logistics, used by thousands of active users.

I thrive in Agile teams and care about clear communication, attention to detail and clean, maintainable code.
